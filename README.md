# mt2-silksong
---

A mod for Monster Train 2 that allies the Skarrlid to the forces of Hell against the Titan incursion, with future plans for the Kingdom of Pharloom as well. The Skarrlid are led by Queen Karmelita and Gurr the Outcast.
